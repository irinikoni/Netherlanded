Prototype v2.1 · Offline-First & Privacy-by-Design

Netherlanded

Personalised arrival checklist, deadline reminders, and scam protection for international students in the Netherlands — paired with a 15-student-floor university insights dashboard and staff content editor.

1. Student Arrival App (PWA) Open →

Full student onboarding flow: EU/non-EU & commuter-municipality setup across 18 study cities (34 municipalities), dependency chain, `.ics` / Google Calendar deadlines, Room Scam Check, and separate Tier 1 / Tier 2 privacy controls.

2. University Insights Dashboard (Demo Mode) Open →

Simulated cohort bottleneck view illustrating the 15-student floor, rounding to 5, tail capping (<= 10.0% / >= 90.0%), and suppressed small-campus handling (THUAS, Leiden, Zoetermeer).

3. Staff Content Editor Panel (Demo Mode) Open →

6-tab editorial workflow showing shared-city locks (`can_edit_city`), institution-specific arrival notes, local GP patient-stop toggles, and `last_verified` fact history.

Static Preview Mode: This GitHub Pages site serves the offline-capable client prototypes and Demo Mode previews with no server tracking or cookies. Live university telemetry requires connecting the PostgreSQL 15/16 + Edge backend (`db/` & `edge/`).
